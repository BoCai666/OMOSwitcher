## 统计分析

---

## 清理原则

### ✅ 保留的日志（必要）

1. **错误日志** - 所有 `error` 级别
   - 启动失败
   - 数据库操作失败
   - 证书生成失败
   - API 调用失败

2. **关键操作日志** - `info` 级别
   - 服务启动/停止
   - 数据库初始化
   - 证书生成
   - 备份创建
   - 配置加载

3. **警告日志** - `warn` 级别
   - 数据库损坏
   - 配置缺失
   - 非关键错误

### ❌ 删除的日志（冗余）

1. **详细调试日志**
   - 每个请求的详细信息
   - 数据内容日志
   - 内部状态日志

2. **重复日志**
   - 同一操作的多次日志
   - 不必要的中间步骤日志

3. **过于频繁的日志**
   - 每个请求的日志
   - 流数据日志
   - 高频操作日志
